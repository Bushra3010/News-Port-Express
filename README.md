# NewsPort Express

Front-end demo of the NewsPort Express Hindi news portal. It is static HTML, CSS and JavaScript with dummy data and no backend.

## Run locally

```bash
python3 -m http.server 8765 --directory site
```

Then open http://localhost:8765.

Live site: https://bushra3010.github.io/News-Port-Express/ (deployed by `.github/workflows/pages.yml` on every push to `main`).

## Files

- `site/index.html` — the whole site: layout, styles, dummy news data and interactions
- `site/logo.jpg` — NewsPort Express logo

All stories, scores, market figures and horoscopes are placeholder content for demo purposes.
